إعداد Google OAuth (مرة واحدة)

التطبيق لا يحتوي أي Client Secret. نحتاج فقط Client ID من مشروعك في Google Cloud.

  1. افتح console.cloud.google.com ← أنشئ مشروعاً جديداً.
  2. فعّل YouTube Data API v3 من مكتبة الـ APIs.
  3. شاشة الموافقة (OAuth consent screen) ← External ← أضف حسابك كـ Test user.
  4. بيانات الاعتماد ← Create Credentials ← OAuth client ID ← النوع: Desktop app.
  5. انسخ Client ID وألصقه هنا (ينتهي بـ .apps.googleusercontent.com).

لا تضع Client Secret هنا — غير مطلوب ولن يُقبل.
